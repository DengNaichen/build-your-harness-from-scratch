# 课程

一课一个文件，按编号排列。新开一课：复制 [TEMPLATE.md](TEMPLATE.md) 为 `NN-短名.md`，再在下面加一行。

写作约定：一课只讲一个可观察的现象；先实验，后解释；默认离线可复现。

| # | 课 | 一句话 |
|---|---|---|
| 00 | [看见模型看到的东西](00-trace.md) | 把每次发给模型的请求按 trace → turn → request 记下来，并能读懂它 |
| 01 | [整文件覆盖的代价](01-edit.md) | `write` 发现不了丢了什么；`edit` 把一次替换变成可失败的断言，并用 trace 看模型是否真的会选它 |
| 02 | [上下文从哪里来](02-context.md) | 把 `AGENTS.md` 拼进 prompt 是三行代码；难的是"哪个文件"和"什么时候重读"——路径规则和重载时机才是要定死的东西 |
